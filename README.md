# NpcWithLLM

Godot-проект для общения игрока с 3D-персонажем, который в дальнейшем будет отвечать с помощью локальной LLM.

## Текущий статус

Проект находится на этапе базового каркаса и использует Godot 4.7. Интеграция с локальной LLM и полноценная сцена с 3D-персонажем будут добавлены на следующих этапах разработки.

## Направление проекта

- диалог игрока с 3D-персонажем;
- локальный запуск языковой модели;
- дальнейшее подключение игрового интерфейса к локальному LLM-сервису.

# Bonsai 2 временно выбрана провайдером игры по умолчанию

Статус: superseded by ADR-0009

Дата: 2026-09-24

## Контекст

В одном свободном 32-ходовом диалоге Bonsai 2 PTQ1_0 получила 4,3/10; `qwen3.5:4b` в отдельной
беседе получила 4,9/10. Bonsai также медленнее, а проверка проводилась на RTX 4070 Ti с 12 ГБ VRAM,
поэтому возможность работы на целевой машине с 8 ГБ не подтверждена. После просмотра этих
результатов пользователь решил сделать Bonsai текущим основным вариантом игры, чтобы продолжить
практическую проверку модели.

## Решение

`LocalLlmConfig.tres` выбирает `LocalLlmProvider.Prism` с OpenAI-compatible endpoint
`http://127.0.0.1:8080/v1/chat/completions` и моделью `Bonsai-2-27B-PTQ1_0`. `LocalLlmResponder`
создаёт `Bonsai2PrismRuntime`; этот runtime проверяет локальный PrismML сервер, отправляет диалог и
буферизует ответ до подтверждения полноты. Ограниченные повторы восстанавливают пустые и некоторые
временные или незавершённые ответы.

Пользовательский выбор меняет текущую конфигурацию, но не меняет смысловой результат оценки: Bonsai
остаётся экспериментальным вариантом для дальнейшей игры, а её пригодность и работа на 8-ГБ карте
не доказаны.

## Ограничения и эксплуатация

- Игра не запускает PrismML. Совместимый runtime и Bonsai GGUF размещаются отдельно; пользователь
  запускает `llama-server` на `127.0.0.1:8080` по инструкции в README.
- Веса, исполняемые файлы PrismML и внешние оценочные артефакты не добавляются в Git или игровую
  поставку.
- При недоступности Prism игра показывает ошибку подключения и сохраняет текст игрока для повтора.
- Для возврата к Ollama выставляются `Provider = 0`, `BaseUrl = "http://127.0.0.1:11434"`,
  `EndpointPath = "/api/chat"` и нужное значение `ModelName`.

## Последствия

- Обычный запуск Godot использует выбранный пользователем Bonsai endpoint без отдельной тестовой
  сцены или подмены runtime.
- Ollama остаётся поддержанным провайдером; оценщик Gemma задаёт его явно, чтобы конфигурация
  по умолчанию проекта не меняла смысл воспроизводимых прогонов.
- После проверки на нужной машине пользователь может выбрать другой провайдер или модель отдельным
  решением.

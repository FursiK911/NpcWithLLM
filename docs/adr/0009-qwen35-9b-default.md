# Qwen3.5 9B выбрана локальной моделью игры

Статус: accepted

По решению пользователя `LocalLlmConfig.tres` выбирает локальную Ollama-модель `qwen35-9b-q4km-bartowski:latest`, заменяя прежнее значение по умолчанию Bonsai 2 из ADR-0007. В 32-ходовой диагностической беседе с JSON Schema Qwen получила 5,5/10 и сохранила имя и профессию игрока, но выдумывала подробности биографии и сцены; без schema-enforcement штатный парсер отклонил ответ на втором ходе. Поэтому JSON Schema передаётся через поле Ollama `format`, а модель остаётся экспериментальным выбором. Оценка выполнена на RTX 4070 Ti с 12 ГБ, и соответствие целевой машине с 8 ГБ VRAM не подтверждено. Веса доступны только из локальной Ollama и не включаются в Git или сборку.

Уточнение от 2026-09-25: тег `qwen35-9b-q4km-bartowski:local` присутствовал в `/api/tags`, но Ollama 0.32.15 отвечала `404 model not found` на `/api/chat`. Тот же manifest под `:latest` успешно запустил генерацию; игровой default переключён на `:latest`, а live-smoke добавлен в `Tests/OllamaConfiguredModelSmoke.ps1`.

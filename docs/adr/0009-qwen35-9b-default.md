# Qwen3.5 9B выбрана локальной моделью игры

Статус: accepted

По решению пользователя `LocalLlmConfig.tres` выбирает локальную Ollama-модель `qwen35-9b-q4km-bartowski:local`, заменяя прежнее значение по умолчанию Bonsai 2 из ADR-0007. В 32-ходовой диагностической беседе с JSON Schema Qwen получила 5,5/10 и сохранила имя и профессию игрока, но выдумывала подробности биографии и сцены; без schema-enforcement штатный парсер отклонил ответ на втором ходе. Поэтому JSON Schema передаётся через поле Ollama `format`, а модель остаётся экспериментальным выбором. Оценка выполнена на RTX 4070 Ti с 12 ГБ, и соответствие целевой машине с 8 ГБ VRAM не подтверждено. Веса доступны только из локальной Ollama и не включаются в Git или сборку.

# Исполняемый runtime игры использует GDScript

Статус: accepted

Игровой runtime реализуется на GDScript и собирается обычным Godot 4.x. Проект не требует Godot .NET или .NET SDK для открытия, запуска, тестирования и экспорта игры. UI, signal seam `ChatResponder`, профиль персонажа, память, история, контекст, генерация, HTTP-запросы и управление Ollama остаются отдельными частями игрового кода.

Это решение выполняет требование использовать GDScript для игры и упрощает запуск проекта на стандартной установке Godot. Оно не меняет выбранную локальную модель, endpoint Ollama, JSON contract, скрытый lifecycle bundled runtime или правила памяти и истории.

## Последствия

- Windows-экспорт выполняется обычным Godot и стандартными export templates без шага `dotnet build`.
- Regression- и smoke-проверки исполняемого runtime написаны на GDScript и запускаются в headless Godot.
- Исторические C#-вспомогательные классы могут оставаться только внутри `Tests/OptionalModelEvaluation/` для необязательной оценки модели через PowerShell 7 `Add-Type`. Они не подключаются к игровой сцене, проекту Godot или экспортируемому пакету и не являются зависимостью приложения.
- Технические предположения о языке реализации в ранних заметках остаются историей предыдущего решения; этот ADR задаёт актуальный язык исполняемого кода.

# Структурированный ответ персонажа включает эмоцию

Чтобы связывать ответ персонажа с его портретом и не показывать служебные поля игроку, локальная модель возвращает единый JSON-объект с текстом реплики и эмоцией; приложение показывает его только после полной проверки. Мы выбираем согласованный текст и портрет вместо раннего потокового вывода, храним в истории только произнесённую реплику, а не JSON; это решение частично заменяет требование о потоковом показе из ADR-0003.

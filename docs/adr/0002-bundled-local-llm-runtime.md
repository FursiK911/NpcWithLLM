# Bundled локальный runtime для LLM

Статус: accepted

Windows-first сборка игры поставляет Ollama CLI и выбранную Gemma 3 270M IT Q4_K_M модель рядом с проектом, запускает Ollama скрытым дочерним процессом и управляет только процессом, который запустила сама игра. Это выбрано вместо обязательного ручного запуска внешнего сервиса, потому что демонстрация должна автоматически подготавливать локальную языковую модель при старте, не показывая пользователю Ollama или терминал, но при этом сохранять заменяемый `ChatResponder` и отдельный инфраструктурный шов `LocalLlmRuntime`.

## Considered Options

- Ручной запуск Ollama: проще для разработки, но не соответствует требованию автоматической подготовки модели.
- Использование установленного Ollama: уменьшает размер проекта, но оставляет обязательную внешнюю зависимость.
- Bundled Ollama CLI: даёт скрытый и воспроизводимый Windows-first запуск, а runtime можно заменить позднее.
- Встраивание inference runtime внутрь процесса Godot: не подходит для 4–6 часов из-за native-зависимостей, GPU backend и усложнения диагностики.

## Consequences

- Архив содержит Windows runtime Ollama, необходимые служебные файлы, SHA-256 runtime-файлов и third-party notices.
- Runtime-файлы для разработки хранятся через Git LFS; комплект для запуска содержит реальные файлы, а не только LFS pointers.
- Веса модели пользователь заранее подготавливает в своей локальной Ollama. Игра их не скачивает, не импортирует и не проверяет их checksum.
- Отсутствие bundled runtime приводит к диагностируемой ошибке и инструкции восстановить runtime; игра не скачивает runtime во время запуска.
- Уже работающий локальный сервис переиспользуется и не завершается игрой; завершается только процесс, запущенный игрой.
- Runtime остаётся Windows-first; игровой seam и HTTP-контракт не должны зависеть от конкретной реализации UI.

Уточнение от 2026-09-22: этот ADR решает способ поставки и запуска runtime, а не выбор модели.
Конкретное имя модели в тексте — историческое название на момент принятия; модель выбирается по
критерию пригодности из ADR-0003.

Уточнение от 2026-09-25: первоначальные последствия ADR о включении модели/`Modelfile`, Git LFS для весов и загрузке модели игрой устарели. Для модели действуют принятое решение в тикете [05](../../.scratch/npc-local-llm-demo/issues/05-verified-model-provisioning.md) и [ADR-0009](0009-qwen35-9b-default.md): веса остаются у пользователя в локальной Ollama, игра не загружает их, а проект не распространяет модель и не публикует для неё checksum. Это уточнение не меняет принятого решения о bundled Ollama runtime.

# Project-local Godot MCP

Статус: accepted

Для работы Codex с этим Godot-проектом используется внешний STDIO-сервер `@coding-solo/godot-mcp@0.1.1`, подключённый через проектный `.codex/config.toml`. Сервер не является Godot-плагином и поэтому не добавляется в `project.godot`: он запускается отдельно и получает путь к проекту через MCP-вызовы. Версия зафиксирована, чтобы обновления npm-пакета не меняли набор инструментов неожиданно.

## Consequences

- Конфигурация действует только для этого доверенного репозитория и не меняет другие проекты.
- Первый запуск `npx` может скачать пакет; для этого задан увеличенный `startup_timeout_sec`.
- `GODOT_PATH` содержит путь Windows, специфичный для текущей машины, и должен быть заменён при другом расположении Godot.
- После изменения конфигурации нужно перезапустить Codex или начать новую локальную сессию, чтобы MCP-сервер был перечитан.
- Рабочий проект остаётся независимым от MCP: в Git не добавляются исходники сервера и зависимости npm.

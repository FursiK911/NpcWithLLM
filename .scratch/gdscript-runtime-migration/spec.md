# Перенос игрового runtime на GDScript

## Цель

Перенести исполняемый путь игры с Godot .NET/C# на GDScript, чтобы проект запускался и экспортировался обычной установкой Godot 4.x без .NET SDK и Godot .NET.

## Требуемое поведение

- Сохранить текущий UI диалога, сигналы жизненного цикла запроса, блокировку ввода до готовности и запрет параллельных запросов.
- Сохранить локальный endpoint Ollama, выбор настроенной модели, JSON contract, ошибки для игрока и правила технического логирования.
- Сохранить временную память NPC и ограниченную историю диалога, включая порядок контекста и обновление состояния только после корректного ответа.
- Разделить UI, память, построение контекста, HTTP runtime и wiring сцен на отдельные модули GDScript за сигнальным seam `ChatResponder`.
- Оставить приложение полностью локальным; для игры не требуется облачный сервис.
- Обновить Windows-экспорт, тесты и документацию для обычного Godot 4.x без шага сборки .NET.

## За рамками задачи

Необязательный harness оценки модели может сохранить отдельные C#-исходники для `Add-Type` в PowerShell 7, если они не подключены к проекту игры или экспортируемому пакету и явно описаны как необязательные.

# 05: Windows-поставка и финальная проверка

**What to build:** Проект поставляется как воспроизводимая Windows-first демонстрация с runtime, моделью, документацией, лицензиями и проверенным сценарием из тестового задания.

**Blocked by:** 04: Тихая подготовка bundled Ollama

**Status:** ready-for-agent

- [ ] В поставке присутствуют Godot-проект, bundled Ollama CLI, реальный файл модели и необходимые служебные файлы.
- [ ] Для модели и runtime опубликованы SHA-256 checksums.
- [ ] README содержит версию Godot, системные требования и ориентир по 8 ГБ VRAM.
- [ ] README описывает выбранную Qwen3.5-модель, Ollama, silent startup, память и ограничение контекста.
- [ ] README описывает восстановление bundled-файлов и поведение при отсутствии сети.
- [ ] В поставке присутствуют лицензия Apache-2.0 Qwen3.5, требования по использованию и third-party notices.
- [ ] Документация не обещает облачный fallback или постоянную память.
- [ ] Чистая Windows-проверка проходит от запуска игры до ответа NPC.
- [ ] Проверяется сценарий с именем и профессией игрока и последующим использованием памяти.
- [ ] Проверяются ошибка отсутствующей модели, timeout, сетевой сбой и ручная повторная отправка.
- [ ] Финальная сборка Godot C# проекта запускается без редактора и не показывает окно Ollama.

# 11: Вступительная модалка для игрока

**What to build:** Показывать при каждом запуске короткое художественное вступление только о том, что игрок видит при входе, прежде чем он сможет начать диалог.

**Status:** ready-for-human
**Resolution:** confirmed

## Требования

- [x] При запуске сцена затемняется, а по центру появляется небольшая модалка. Её закрывает только кнопка «OK» внизу по центру; щелчок по фону или клавиатурная команда не закрывают её.
- [x] Заголовок называет место, но не раскрывает имя незнакомого игроку механика.
- [x] Вступление хранится в отдельном поле `NpcProfile.PlayerIntroduction`. Расширенное поле `NpcProfile.Situation` остаётся контекстом NPC и передаётся модели отдельно; модалка его не отображает.
- [x] Короткая художественная сцена связно показывает игроку вход в мастерскую, механика рядом с серым фургоном и его видимую реакцию на появление посетителя; текст не читается как перечень фактов.
- [x] Вступление не раскрывает имени механика, состояние двигателя, догадки о цели визита, намерения или правила поведения NPC.
- [x] Пока модалка открыта, сообщение нельзя вводить или отправить, а элементы сцены под ней не получают ввод. Если игрок закрыл модалку до завершения подготовки NPC, ввод остаётся заблокированным до готовности персонажа.
- [x] После закрытия модалки и готовности NPC поле ввода и кнопка отправки становятся доступны.
- [x] Поведение проверяется на шве основной сцены с управляемым fake runtime: видимость и содержимое вступления, единственный способ закрытия, блокировка элементов под ним и оба порядка готовности NPC относительно нажатия «OK».

## Контекст

Использовать термины проекта: персона, ситуация, вступление для игрока и персонаж. Ситуация — более полный контекст NPC; вступление описывает только доступную игроку сцену. Решение и пользовательские истории записаны в родительской спецификации.

# 09: Проверка чистого Windows-запуска

**What to build:** Чистая Windows-машина проходит путь от запуска поставленной игры до ответа NPC и корректно показывает основные ошибки подготовки и генерации.

**Blocked by:** 07: Состояние подготовки модели в игре; 08: Windows-поставка и документация

**Status:** ready-for-agent

- [ ] Финальная сборка стартует без редактора Godot и не показывает консольное окно Ollama.
- [ ] После подготовки игрок получает ответ от локальной модели в сцене.
- [ ] Сценарий с сообщением имени и профессии подтверждает их последующее использование NPC.
- [ ] Повторно проверяются ошибки отсутствующей модели, отсутствия сети, неверного checksum, timeout и сетевой ошибки.
- [ ] После ошибки генерации введённое сообщение сохраняется, а игрок может повторить отправку вручную.
- [ ] При завершении игры внешний Ollama остаётся запущенным, а созданный игрой процесс закрывается.
- [ ] Запуск и диалог не обращаются к облачному API.

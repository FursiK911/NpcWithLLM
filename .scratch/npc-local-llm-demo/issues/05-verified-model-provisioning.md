# 05: Проверенная подготовка модели

**What to build:** Перед диалогом Ollama получает закреплённую модель `qwen3.5:4b`, проверенную по checksum и подготовленную к локальной генерации.

**Blocked by:** 04: Скрытый жизненный цикл Ollama

**Status:** ready-for-agent

- [ ] Версия и источник модели зафиксированы для поставки; вместе с моделью сохраняются её происхождение и лицензия.
- [ ] Bundled-файл модели проверяется по SHA-256 до импорта или использования.
- [ ] Если bundled-файла нет, модель загружается из настроенного источника с доступным для интерфейса прогрессом.
- [ ] Загруженный файл проверяется по SHA-256 до импорта; несовпадение checksum блокирует использование модели.
- [ ] Проверенный GGUF импортируется в Ollama воспроизводимым подготовительным шагом через `Modelfile`.
- [ ] Модель прогревается до того, как runtime объявит её готовой к диалогу.
- [ ] Отсутствие сети, повреждённый файл и ошибка импорта дают диагностируемую причину и не включают mock-ответчик.

# 04: Тихая подготовка bundled Ollama

**What to build:** При старте игры bundled Ollama и Qwen3.5 0.8B скрыто подготавливаются, после чего диалог становится доступен.

**Blocked by:** 03: Настоящий ответ локальной LLM

**Status:** ready-for-agent

- [ ] Игра проверяет SHA-256 Ollama CLI и файла модели до запуска.
- [ ] Ollama CLI запускается без видимого консольного окна.
- [ ] Уже работающий endpoint на `127.0.0.1:11434` переиспользуется.
- [ ] Игра отслеживает только собственный процесс и не завершает внешний Ollama.
- [ ] GGUF-модель импортируется через `Modelfile` скрытым подготовительным шагом.
- [ ] После импорта модель прогревается до разрешения пользовательского ввода.
- [ ] Сцена отображается во время подготовки и показывает понятный статус и прогресс.
- [ ] Повреждённый или отсутствующий файл не запускается и даёт диагностируемую ошибку.
- [ ] При отсутствии bundled-файлов игра может скачать их из настроенного источника с прогрессом.
- [ ] Скачанный файл проверяется по SHA-256 до использования.
- [ ] Отсутствие сети приводит к понятной ошибке с инструкцией, без mock-подмены.
- [ ] При закрытии игры завершается только процесс, запущенный этой игрой.
- [ ] Ручная Windows-проверка подтверждает отсутствие окна Ollama и готовность диалога после запуска.

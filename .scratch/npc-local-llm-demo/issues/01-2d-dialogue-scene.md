# 01: Играбельная 2D-сцена диалога

**What to build:** Игрок запускает игру, видит простую 2D-сцену с NPC и может вести базовый диалог через mock-ответчик.

**Blocked by:** None (can start immediately)

**Status:** ready-for-human
**Resolution:** confirmed

- [x] Основная сцена запускается в Godot 4.7 C# как 2D-сцена.
- [x] На сцене присутствуют placeholder-NPC и минимальная панель диалога.
- [x] Игрок может отправить сообщение кнопкой и клавишей Enter.
- [x] Shift+Enter вставляет перенос строки, а не отправляет сообщение.
- [x] Пустое сообщение не запускает запрос.
- [x] Во время ожидания mock-ответа поле и кнопка заблокированы.
- [x] Повторная отправка во время активного запроса невозможна.
- [x] Успешный ответ отображается, а поле ввода очищается.
- [x] Ошибка mock-провайдера отображается, а введённый текст сохраняется.
- [x] Панель остаётся usable после изменения размера окна.
- [x] Сборка и запуск основной сцены проходят без ошибок.

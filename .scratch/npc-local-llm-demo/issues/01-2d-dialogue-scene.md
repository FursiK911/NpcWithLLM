# 01: Играбельная 2D-сцена диалога

**What to build:** Игрок запускает игру, видит простую 2D-сцену с NPC и может вести базовый диалог через mock-ответчик.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Основная сцена запускается в Godot 4.7 C# как 2D-сцена.
- [ ] На сцене присутствуют placeholder-NPC и минимальная панель диалога.
- [ ] Игрок может отправить сообщение кнопкой и клавишей Enter.
- [ ] Shift+Enter вставляет перенос строки, а не отправляет сообщение.
- [ ] Пустое сообщение не запускает запрос.
- [ ] Во время ожидания mock-ответа поле и кнопка заблокированы.
- [ ] Повторная отправка во время активного запроса невозможна.
- [ ] Успешный ответ отображается, а поле ввода очищается.
- [ ] Ошибка mock-провайдера отображается, а введённый текст сохраняется.
- [ ] Панель остаётся usable после изменения размера окна.
- [ ] Сборка и запуск основной сцены проходят без ошибок.

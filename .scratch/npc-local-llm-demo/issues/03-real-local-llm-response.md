# 03: Настоящий ответ локальной LLM

**What to build:** Игра получает настоящий ответ от локально работающего Ollama через `LocalLlmRuntime`, не раскрывая детали runtime игровому UI.

**Blocked by:** 02: Память персонажа и ограниченный контекст

**Status:** ready-for-agent

- [ ] Настройки подключения, имя модели, timeout и параметры генерации редактируются без изменения UI-логики.
- [ ] `LocalLlmResponder` реализует тот же lifecycle, что и mock-ответчик.
- [ ] Запрос содержит persona, состояние, память, ограниченную историю и текущую реплику.
- [ ] Успешный непустой ответ локальной модели отображается в UI.
- [ ] Полный ответ обрабатывается без streaming.
- [ ] HTTP error, network error, timeout, некорректный JSON и пустой ответ превращаются в понятную ошибку UI.
- [ ] Технические детали ошибки пишутся в debug log без полного текста диалога.
- [ ] Второй запрос во время активного запроса отклоняется.
- [ ] Ошибка не добавляет сообщение в историю и не стирает ввод игрока.
- [ ] Fake runtime покрывает успешный ответ и основные классы ошибок.
- [ ] Ручной запуск подготовленного Ollama подтверждает реальный end-to-end ответ в сцене.

# 07: Состояние подготовки модели в игре

**What to build:** Игрок видит, что происходит при запуске, и может начать диалог только после готовности локальной модели.

**Blocked by:** 04: Скрытый жизненный цикл Ollama; 05: Проверенная подготовка модели

**Status:** ready-for-agent

- [ ] Игровая сцена остаётся видимой во время подготовки runtime и модели.
- [ ] Интерфейс показывает понятный текущий этап подготовки и прогресс загрузки модели, когда он доступен.
- [ ] Поле ввода и отправка диалога недоступны, пока Ollama и модель не готовы.
- [ ] Ошибки отсутствующего runtime или модели, недоступной сети и неуспешной подготовки показаны понятным игроку сообщением.
- [ ] При ошибке диалог не переключается на mock-ответчик.

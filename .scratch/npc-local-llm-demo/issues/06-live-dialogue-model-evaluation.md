# 06: Живая оценка локальной модели

**What to do:** Провести свободный диалог с текущей локальной моделью, оценить речь NPC по нескольким критериям и дать пользователю аргументированную рекомендацию оставить или заменить модель.

**Type:** research

**Blocked by:** 03: Настоящий ответ локальной LLM

**Status:** ready-for-human

- [x] Используются текущие профиль персонажа, контекст, память, история и настройки модели из игры.
- [x] На неполном практическом вопросе проверено, уточняет ли NPC недостающие сведения; разговорность и грамотность речи оценены в отчёте.
- [x] Оценщик ведёт один связный разговор из 32 реплик игрока и ответов персонажа.
- [x] Следующая реплика выбирается по предыдущему ответу NPC; заранее подготовленный список вопросов не используется.
- [x] Оцениваются сохранение личности и роли, связность, уместность, фактическая аккуратность, грамотность русского языка, естественность речи, память в границах контекста и отсутствие повторов.
- [x] Каждая оценка выставляется по шкале от 1 до 10 и подкрепляется примерами из беседы.
- [x] Итог содержит оценки, наблюдаемые ограничения и рекомендацию оставить текущую модель или проверить замену.
- [x] Окончательный выбор модели остаётся за пользователем; загрузка кандидата не запускается автоматически.

# 04: Скрытый жизненный цикл Ollama

**What to build:** Игра подключается к уже работающему локальному Ollama или незаметно запускает свой экземпляр и закрывает только процесс, которым владеет.

**Blocked by:** 03: Настоящий ответ локальной LLM

**Status:** ready-for-agent

- [ ] Перед запуском bundled Ollama CLI проверяется его ожидаемый SHA-256.
- [ ] Если endpoint `127.0.0.1:11434` уже отвечает, игра использует его и не запускает второй экземпляр.
- [ ] Если endpoint недоступен, игра запускает bundled Ollama CLI без видимого консольного окна.
- [ ] Игра различает внешний и собственный процесс Ollama и завершает только собственный при выходе или неудачной подготовке.
- [ ] Ошибка запуска или подключения доступна интерфейсу как диагностируемое состояние; mock-ответчик не подменяет локальную модель.
- [ ] Ручной Windows-smoke подтверждает повторное использование внешнего endpoint и скрытый запуск собственного процесса.

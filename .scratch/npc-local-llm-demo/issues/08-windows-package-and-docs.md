# 08: Windows-поставка и документация

**What to build:** Разработчик получает воспроизводимый Windows-комплект с игрой, Ollama, выбранной моделью и достаточной документацией для запуска и восстановления.

**Blocked by:** 04: Скрытый жизненный цикл Ollama; 05: Проверенная подготовка модели

**Status:** ready-for-agent

- [ ] ZIP-поставка содержит Godot C# проект, bundled Ollama CLI, модель `qwen35-9b-q4km-bartowski:latest` и необходимые служебные файлы.
- [ ] Для поставленных runtime и модели опубликованы SHA-256 checksums.
- [ ] README указывает версию Godot, системные требования Windows и целевой ориентир по 8 ГБ VRAM.
- [ ] README описывает выбранную модель, Ollama, запуск, память NPC, ограничение истории и восстановление bundled-файлов.
- [ ] README явно описывает поведение при отсутствии сети и не обещает облачный fallback или постоянную память.
- [ ] Поставка содержит лицензию Apache-2.0 Qwen3.5, применимые требования к использованию Ollama и third-party notices.
- [ ] Dev checkout использует согласованный способ хранения крупных bundled-файлов через Git LFS.

# 08: Windows-поставка и документация

**What to build:** Разработчик получает воспроизводимый Windows-комплект с Godot C# проектом, bundled Ollama runtime и достаточной документацией для запуска и восстановления. Выбранная модель заранее устанавливается пользователем в локальную Ollama и в комплект не входит.

**Blocked by:** 04: Скрытый жизненный цикл Ollama; 05: Проверенная подготовка модели

**Status:** ready-for-human

- [x] ZIP-поставка содержит Godot C# проект, закреплённый bundled Ollama CLI/runtime и необходимые служебные файлы; веса модели в ZIP не входят.
- [x] Для всех поставленных runtime-файлов опубликован SHA-256 манифест. Для модели checksum не публикуется, поскольку проект её не распространяет.
- [x] README указывает версию Godot, системные требования Windows и целевой ориентир по 8 ГБ VRAM.
- [x] README описывает выбранную модель (`qwen35-9b-q4km-bartowski:latest`), Ollama, запуск, память NPC, ограничение истории и восстановление bundled-файлов.
- [x] README явно описывает поведение при отсутствии сети и не обещает облачный fallback или постоянную память.
- [x] Поставка содержит Apache-2.0 Qwen3.5 как уведомление о отдельно устанавливаемой модели, MIT Ollama, тексты лицензий llama.cpp и найденных зависимостей из закреплённого исходника, а также ссылки на условия CUDA и Microsoft Visual C++ runtime.
- [x] Dev checkout использует Git LFS для крупных bundled runtime-файлов; веса модели не хранятся в LFS.

## Comments

- 2026-09-25: Уточнён конфликт исходных критериев с принятым решением тикета 05 и ADR-0009. Их условия имеют приоритет: модель хранится только в локальной Ollama пользователя, игра её не скачивает, а Git/ZIP не содержат веса или checksum модели. Поэтому устаревшие требования включить модель и её checksum заменены критериями для bundled Ollama runtime; это не меняет решение о модели.
